# Programación II

Repositorio académico para la materia **Programación II**, donde se almacenarán, organizarán y versionarán los proyectos, ejercicios y subproyectos desarrollados durante el curso.

## Contenido

Este repositorio está organizado por las principales tecnologías y herramientas trabajadas en la materia:

- 🐍 **Python** — ejercicios, prácticas y proyectos desarrollados con Python.
- 🌐 **Django** — proyectos web, aplicaciones y prácticas realizadas con el framework Django.
- 🏢 **Odoo** — módulos, personalizaciones y proyectos desarrollados sobre Odoo.

## Organización de proyectos

Cada proyecto tendrá su propia carpeta para facilitar el control y seguimiento del desarrollo.

Ejemplo:

```text
Python/
└── Proyecto_01/
    ├── subproyecto_01/
    ├── subproyecto_02/
    ├── README.md
    └── archivos_del_proyecto
```

Para Django:

```text
Django/
└── Proyecto_01/
    ├── app/
    ├── templates/
    ├── static/
    ├── manage.py
    └── README.md
```

Para Odoo:

```text
Odoo/
└── Proyecto_01/
    ├── addons/
    ├── modulo_personalizado/
    └── README.md
```

## Control de versiones

El repositorio utiliza **Git** para llevar un registro de los cambios realizados en cada proyecto.

Ejemplo de flujo de trabajo:

```bash
git add .
git commit -m "Agrega proyecto de Python"
git push
```

Para actualizar el repositorio:

```bash
git pull
```

## Proyectos pasados

La carpeta `Proyectos_Pasados/` permitirá conservar y organizar trabajos realizados anteriormente durante la materia.

Esto facilita:

- Consultar proyectos anteriores.
- Revisar versiones anteriores.
- Reutilizar conocimientos y estructuras.
- Mantener un historial organizado de prácticas y proyectos.

## Buenas prácticas

- Utilizar nombres claros para carpetas y archivos.
- Mantener cada proyecto dentro de su categoría correspondiente.
- Crear un `README.md` cuando un proyecto necesite documentación propia.
- Realizar commits con mensajes descriptivos.
- No subir contraseñas, claves SSH, archivos `.env` ni información sensible.
- Mantener actualizado el repositorio.

## Objetivo

El objetivo de este repositorio es mantener un **control organizado de los proyectos y subproyectos de Programación II**, utilizando Git y GitHub como herramientas de control de versiones y documentación.
